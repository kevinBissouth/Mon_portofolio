# Mon_portofolio
My personal portofolio website built using HTML, Tailwindcss and javascript.

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

Recompile `src/output.css` à chaque modification de `src/input.css` ou du HTML.

## Build

```bash
npm run build
```

Génère `src/output.css` minifié, à lancer avant de publier le site.
